# شارك أي حاجة (ShareAnything)

تطبيق أندرويد بسيط يخليك تختار أي ملف من جهازك وتشاركه بأكتر من طريقة:

1. **شير شيت أندرويد العادي** — تشاركه على واتساب، تليجرام، إيميل، أو أي تطبيق تاني مثبت عندك.
2. **مشاركة عبر الواي فاي المحلي** — التطبيق يشغّل سيرفر صغير جوه الجهاز، ويطلعلك لينك و QR code، وأي جهاز على نفس شبكة الواي فاي يقدر يفتح اللينك أو يمسح الكود وينزّل الملف على طول من المتصفح، من غير إنترنت خارجي.

## المتطلبات
- Android Studio (Koala أو أحدث)
- JDK 17
- Android SDK (compileSdk 34, minSdk 24)

## طريقة التشغيل
1. افتح المجلد ده في Android Studio: `File > Open`
2. سيب Android Studio يعمل Sync للـ Gradle (هيحمل الـ wrapper تلقائي أول مرة)
3. دوس Run ▶️ على جهاز حقيقي أو إيموليتور

## البنية
```
app/
 └─ src/main/
     ├─ java/com/shareanything/app/
     │   ├─ MainActivity.kt        // واجهة المستخدم (Jetpack Compose)
     │   ├─ LocalShareServer.kt    // سيرفر HTTP خفيف للمشاركة عبر الواي فاي
     │   ├─ QrCode.kt              // توليد QR code من رابط المشاركة
     │   └─ FileUtils.kt           // قراءة ونسخ الملف المختار
     ├─ res/                       // الموارد (ثيمات، أيقونات، نصوص)
     └─ AndroidManifest.xml
```

## ملاحظات تقنية
- التطبيق بيستخدم `Storage Access Framework` (`ActivityResultContracts.OpenDocument`) عشان يقرأ أي نوع ملف من غير ما يحتاج صلاحيات تخزين واسعة.
- الملف المختار بيتنسخ لمجلد كاش داخلي (`cacheDir/shared/`) عشان يتقدر يتعرض بأمان عن طريق `FileProvider` وكمان يتقرأ من السيرفر المحلي.
- سيرفر الواي فاي مبني بـ raw sockets (`ServerSocket`) من غير أي مكتبة خارجية، فبيدعم طلب GET واحد بيرجّع بيانات الملف كامل مع `Content-Disposition` عشان يتحمل صح في المتصفح.
- توليد الـ QR code بمكتبة `zxing-core` (بدون اعتمادية على كاميرا أو مسح، توليد بس).

## تطوير مستقبلي مقترح
- دعم Bluetooth كطريقة مشاركة تالتة.
- دعم اختيار أكتر من ملف مرة واحدة (ضغطهم في zip قبل الإرسال).
- عرض progress bar أثناء التحميل من السيرفر المحلي.
